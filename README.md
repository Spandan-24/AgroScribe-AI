🌿 AgroScribe AIAI-Powered Plant Disease Detection for West Bengal FarmersAgroScribe AI is a Flask-based web application that uses a trained Convolutional Neural Network (CNN) to detect plant diseases from leaf images. It provides instant diagnosis, severity and urgency indicators, organic and chemical treatment recommendations, pesticide suggestions, live weather updates with 7-day forecasts, district-wise pesticide shop listings across West Bengal, and built-in farmer support.✨ Features🔬 AI Disease Detection — Upload a leaf photo and get an instant diagnosis using a trained TensorFlow/Keras CNN model (15 disease classes across Pepper, Potato, and Tomato with 92% classification accuracy).📊 Confidence Score & Severity — Visual confidence bar, severity rating (Low / Medium / High), and urgency-based color coding (Low / Medium / High / Critical).💊 Treatment Recommendations — Detailed immediate action, treatment, prevention, organic alternatives, and estimated yield loss for each disease.🧪 Pesticide Suggestions — Recommended pesticide products with brand, company, type, and indicative price mapped to the predicted disease.🌤️ Live Weather — Real-time weather based on the user's geolocation (via OpenWeatherMap API), with an agricultural advisory tip.📅 7-Day Forecast — Daily high/low temperatures and rain probability for the upcoming week.🏪 Pesticide Shop Directory — District-wise list of pesticide/agro shops across 20 districts of West Bengal.📖 Disease Library — Searchable guide covering pathogen, symptoms, causes, treatment, and organic options for major crop diseases.🗓️ Crop Sowing Calendar — Seasonal sowing windows and disease-risk indicators for major West Bengal crops.🆘 Help & Support Widget — Floating support button with helpline, WhatsApp chat, email, agri-expert contact (via KVK), and FAQs.🎨 Modern UI — Glassmorphism design, animated gradients, and responsive layout for mobile and desktop.🗂️ Project StructureAgroScribe-AI/

🚫 Excluded via .gitignoreTo keep the repository lightweight and secure, the following files and directories are excluded from version control:venv/ & __pycache__/ — Local Python virtual environment and compiled bytecode files.models/*.h5 — Large trained TensorFlow/Keras model weights (agro_cnn.h5).static/outputs/* — Temporary leaf images uploaded during local inference..env — Private API keys and local environment variables.🧠 Model DetailsThe CNN model (agro_cnn.h5) is trained in TensorFlow/Keras to classify the following 15 classes:CropClassesPepperBacterial Spot, HealthyPotatoEarly Blight, Late Blight, HealthyTomatoBacterial Spot, Early Blight, Late Blight, Leaf Mold, Septoria Leaf Spot, Spider Mites (Two-Spotted), Target Spot, Yellow Leaf Curl Virus, Mosaic Virus, HealthyDataset Split: 70% Training / 20% Testing / 10% ValidationClassification Accuracy: 92% across all 15 disease classesInput Size: 224 × 224 pixelsPreprocessing: Pixel normalization (/ 255.0)Output: Softmax probabilities → class with highest confidence is returned⚠️ Model File Notice: The trained model file (agro_cnn.h5) is not included in this repository due to file size limits. Place your trained model inside the models/ folder before running the app, or train your own using the PlantVillage Dataset.⚙️ Setup & Installation1.
